# DevTechOps Solutions logo

The "prompt" mark (`>_` in a rounded square) with the DevTechOps wordmark. The wordmark is
Inter Bold and SemiBold (SIL Open Font License), converted to outlines, so no font is needed.

| File | Use |
|---|---|
| `lockup.svg`, `lockup-1200.png` | logo with name, on light backgrounds |
| `lockup-dark.svg`, `lockup-dark-1200.png` | logo with name, on dark backgrounds |
| `mark.svg`, `mark-512.png` | the mark alone, on light backgrounds |
| `mark-dark.svg` | the mark alone, on dark backgrounds |
| `avatar.svg`, `avatar-512.png` | square profile picture (LinkedIn, GitHub, email); survives a circular crop |
| `favicon.ico`, `favicon-16.png`, `favicon-32.png`, `apple-touch-icon.png` | browser and home-screen icons |

Colours: navy `#0b2350`, blue `#1f6feb` ("Tech", and the tile on dark), light blue `#7fb3ff`
(the `>`), grey `#5b6a80` ("SOLUTIONS").

Keep clear space around the logo of at least the height of the `>`; don't recolour, stretch or
rotate it.
